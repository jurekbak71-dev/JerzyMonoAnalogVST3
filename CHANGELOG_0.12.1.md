# 0.12.1 — GUI readability and fader controls

- Increase control captions and numeric value fonts by approximately 15%, scaling their display fields with the editor size.
- Replace horizontal blue thumb dots with square brass/metal console fader caps, approximately 15% larger, matching rotary controls.
- Narrow AMP and MOD envelope fader caps; retain a comfortable drag target and centred stage labels.
- Relative fader dragging avoids value jumps; right-click neutral reset remains available.
- Render the title and subtitle on one plaque, with separate non-overlapping text rows.
- Separate OSC1 PULSE WIDTH and PAN caption fields.
- Align GRID groove controls in three equal columns and two knob rows; align the NOTE GATE switch and selected-note caption along the bottom row.
- Use portable ASCII separators in captions to avoid malformed arrow and bullet literals.

Audio DSP, host automation parameter IDs and saved preset structure are unchanged.
