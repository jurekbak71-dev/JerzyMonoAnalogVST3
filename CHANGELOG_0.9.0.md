# Jerzy Mono Analog Grid 0.9.0

- Respaced controls and labels on all six console pages. The Grid's former
  explanation panel is replaced by an enlarged step matrix and groove controls.
- Grid and Arp swing work with host PPQ synchronization; Grid gate and ratchets
  start at the correct boundary. Ping-Pong Grid playback returns through steps.
- Added four bipolar filter-envelope destinations: OSC 2 pitch, resonance,
  mixer drive and amplifier. New parameter IDs are appended for preset and
  automation compatibility; old projects restore zero modulation depth.
- Enlarged readouts and repaired unit formatting on the Grid and FX pages.
- Added DSP tests for PPQ swing boundaries and audible envelope destinations.
